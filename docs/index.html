Funktioner

Gjort for verkligt skrivarbete.

Appen ar liten nog att leva i systemfacket men robust nog for mail, editorer, webblasare, terminaler och interna verktyg.

01

KBLab Whisper

Svenska Whisper-modeller fran Kungliga biblioteket, med CUDA-stod for snabbare lokal transkribering.

02

Tydlig indikator

Lyssnarrutan kan folja muspekaren over flera skarmar eller ligga fast pa huvudskarmen.

03

CLI-vänlig clipboard

Texten stannar i urklipp aven om automatisk paste inte fungerar i en terminal.

04

Personlig ordlista

Ratta vanliga felhorningar, namn och facktermer en gang och ateranvand lokalt.

05

Valfri LLM

Eftergranska text via GitHub Models och se direkt om den ar lokal, LLM-granskad eller LLM-polerad.

06

Automatiska builds

Windows-exe byggs med GitHub Actions och publiceras som artifact for enkel testning.

Integritet

Lokalt forst. Moln bara nar du valjer det.

Standardlaget skickar inte ljud eller transkriberad text till en LLM. LLM-granskning ar separat och tydligt markerad i indikatorn.

Whisper kor lokalt

Ljud spelas in, resamplas och transkriberas pa din Windows-dator. Modeller och ordlistor ligger i anvandarmappen.
